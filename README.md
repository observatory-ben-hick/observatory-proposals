# The Observatory · proposals

Static proposal pages served by GitHub Pages and shown at theobservatory.je.

- `originalthinking/` is the master proposal (theobservatory.je/originalthinking).
- Each page is self-contained: `index.html` plus its `assets/` folder (images, the showreel film).
- Pages are built and updated by Claude from the master template. Edit through Claude rather than by hand, or the next update will overwrite hand edits.
